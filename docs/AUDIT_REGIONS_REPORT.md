# Аудит регионов

Проверка выполнена по той же схеме, что для Москвы и Санкт-Петербурга: число районов, суммарная площадь, отсутствие геометрии, дубликаты имён, сильные расхождения площади с ожидаемой.

**Исправления внесены (по согласованию):**
- Санкт-Петербург: из состава города удалён Ломоносовский муниципальный район (он относится к Ленинградской области; в СПб с 2003 года его территория входит в Петродворцовый район). В СПб осталось 18 районов.
- Республика Ингушетия: удалены 7 ошибочно привязанных записей с названиями районов Адыгеи (Кошехабльский, Гиагинский, Тахтамукайский и др.).
- Чеченская Республика: загружена геометрия для Шалинского муниципального района.

## Общая статистика

- **Регионов:** 89  
- **Районов всего:** 2391  
- **Районов без геометрии:** 8

**Примечание:** У Ингушетии в списке «без геометрии» указаны районы с названиями, характерными для **Республики Адыгея** (Кошехабльский, Майкопский и т.д.). Возможна ошибочная привязка к региону (неверный `region_id`) или дублирование записей. Имеет смысл проверить, к какому региону эти записи должны относиться.

### 2. Дубликаты имён

По результатам проверки дубликатов имён внутри одного региона **не обнаружено**.

## Рекомендуемые действия (только после вашего согласия)

1. **Республика Ингушетия и Республика Адыгея**  
   Проверить привязку к региону у семи районов без геометрии (Кошехабльский, Гиагинский, Тахтамукайский, Теучежский, Шовгеновский, Красногвардейский, Майкопский): при необходимости переназначить `region_id` на Адыгею и/или подгрузить геометрии из OSM.

2. **Чеченская Республика**  
   Подгрузить геометрию для Шалинского муниципального района из OSM (или другого источника).

3. **Архангельская область, ЯНАО и др.**  
   При необходимости — точечно проверить покрытие территории (отсутствующие районы/острова) и при желании дополнять или уточнять границы.

Повторный полный отчёт можно получить командой:
```bash
cd backend && python scripts/audit_all_regions.py
```
