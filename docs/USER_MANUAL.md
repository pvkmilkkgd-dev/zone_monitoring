## 1. Общие сведения

Система мониторинга обстановки предназначена для:
- Визуального отображения событий на карте региона
- Управления событиями различной важности
- Категоризации событий по слоям и подслоям
- Формирования отчётов и выгрузки данных

---

## 2. Роли пользователей

В системе предусмотрены следующие роли:

| Роль | Описание | Доступные функции |
|------|----------|-------------------|
| **Администратор** (admin) | Полный доступ ко всем функциям | Настройки системы, управление пользователями, зонами, слоями, событиями, журнал аудита |
| **Старший редактор** (editor_plus) | Расширенные права редактирования | Редактирование всех событий, слоёв, формирование отчётов |
| **Редактор** (editor) | Базовые права редактирования | Создание событий, редактирование только своих событий |
| **Наблюдатель** (viewer) | Только просмотр | Просмотр карты обстановки |

---

## 3. Вход в систему

1. Откройте браузер и перейдите по адресу системы
2. Введите ваш **логин** и **пароль**
3. Нажмите кнопку **«Войти»**

После успешного входа вы будете перенаправлены:
- **Администратор** → Страница настроек (`/admin`)
- **Редактор / Старший редактор** → Страница событий (`/editor/events`)
- **Наблюдатель** → Страница обстановки (`/situation`)

> **Примечание:** Сессия действует **2 часа**. После истечения этого времени потребуется повторный вход.

---

## 4. Страница обстановки (/situation)

Главная страница с интерактивной картой региона.

### Элементы интерфейса:

**Верхняя панель:**
- **Фильтр по слоям** — выбор отображаемых категорий событий
- **Название управления** — отображается по центру
- **Кнопка «Панель управления»** (иконка домика) — переход к редактированию (только для редакторов и администраторов)
- **Кнопка «Выход»** — выход из системы

**Карта:**
- Районы окрашены в зависимости от важности событий:
  - 🟢 **Зелёный** — низкая важность (1-3)
  - 🟡 **Жёлтый** — средняя важность (4-6)
  - 🔴 **Красный** — высокая важность (7-10)
- При клике на район открывается боковая панель с информацией

**Боковая панель (при выборе района):**
- Название района и подразделения
- Список событий в данном районе
- При клике на событие — подробная информация и комментарии

**Нижний левый угол:**
- Легенда важности событий
- Имя текущего пользователя

## 5. Работа с событиями

*Доступно для: администратор, старший редактор, редактор*

### Страница событий (`/editor/events`)

**Создание события:**
1. Нажмите **«Создать событие»**
2. Заполните поля:
   - **Название** — краткое описание события (обязательно)
   - **Важность** — от 1 до 10 (влияет на цвет района на карте)
   - **Статус** — текущее состояние (В норме / Внимание / Тревога)
   - **Район** — место события (обязательно)
   - **Слой** — категория события
   - **Описание** — подробная информация
3. Прикрепите файлы (при необходимости):
   - **Изображения** — фото, скриншоты
   - **Документы** — Word, PDF и др.
4. Нажмите **«Создать»**

**Редактирование события:**
1. Найдите событие в списке
2. Кликните на него для открытия
3. Нажмите **«Редактировать»**
4. Внесите изменения
5. Нажмите **«Сохранить»**

> **Важно:** Редактор может редактировать только созданные им события. Старший редактор и администратор могут редактировать все события.

**Удаление события:**
1. Откройте событие
2. Нажмите **«Удалить»**
3. Подтвердите удаление

**Фильтрация событий:**
- По слою
- По статусу
- По важности
- По дате
- Архивные/активные

**Комментарии:**
- В карточке события можно добавлять комментарии
- Комментарии видны всем пользователям
- Удалить можно только свои комментарии (или любые — для администратора)

## 6. Работа со слоями

*Доступно для: администратор, старший редактор, редактор*

### Страница слоёв (`/editor/layers`)

Слои используются для категоризации событий.

**Структура:**
- **Слой** (верхний уровень)
  - **Подслой** (второй уровень)
    - **Под-подслой** (третий уровень)

**Создание слоя:**
1. Нажмите **«Добавить слой»**
2. Введите название
3. Нажмите **«Сохранить»**

**Создание подслоя:**
1. Найдите родительский слой
2. Нажмите **«Добавить подслой»**
3. Введите название
4. Нажмите **«Сохранить»**

**Редактирование/удаление:**
- Используйте соответствующие кнопки рядом с названием слоя

## 7. Отчёты

*Доступно для: администратор, старший редактор, редактор*

### Страница отчётов (`/editor/reports`)

**Просмотр событий:**
- Таблица со всеми событиями
- Фильтрация по различным параметрам

**Экспорт в Excel:**
1. Настройте фильтры (при необходимости)
2. Нажмите **«Экспорт в Excel»**
3. Файл `.xlsx` будет скачан

**Экспорт в Word:**
1. Выберите конкретное событие
2. Нажмите **«Экспорт в Word»**
3. Файл `.docx` с детальной информацией будет скачан

## 8. Администрирование

*Доступно только для: администратор*

### 8.1. Настройки системы (`/admin`)

- **Название управления** — отображается на странице обстановки
- **Выбор региона** — определяет карту для отображения

### 8.2. Зоны и устройства (`/admin/zones`)

Управление административными зонами:
- Создание зон
- Привязка районов к зонам
- Назначение подразделений

### 8.3. Пользователи (`/admin/users`)

**Создание пользователя:**
1. Нажмите **«Добавить пользователя»**
2. Заполните:
   - Логин
   - Пароль (минимум 6 символов)
   - Полное имя (опционально)
   - Роль
3. Нажмите **«Создать»**

**Управление пользователями:**
- Изменение роли
- Сброс пароля
- Редактирование данных

### 8.4. Журнал аудита (`/admin/journal`)

Просмотр истории действий в системе:
- Кто и когда выполнил действие
- Тип действия (создание, изменение, удаление)
- Затронутые объекты

## Горячие клавиши и советы

- **Escape** — закрытие модальных окон
- Клик вне модального окна — закрытие
