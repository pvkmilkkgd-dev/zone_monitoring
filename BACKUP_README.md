# Инструкция по созданию резервной копии проекта

## Создание резервной копии

Запустите скрипт `create_backup.ps1` из корневой директории проекта:

```powershell
.\create_backup.ps1
```

Скрипт автоматически:
1. Создаст дамп базы данных PostgreSQL
2. Скопирует все файлы проекта (исключая node_modules, __pycache__, .git и т.д.)
3. Создаст ZIP-архив со всем содержимым
4. Сохранит архив в папку `backup/`

Архив будет иметь имя вида: `zone_monitoring_backup_YYYY-MM-DD_HH-mm-ss.zip`

## Восстановление из резервной копии

Для восстановления проекта из архива используйте скрипт `restore_backup.ps1`:

```powershell
.\restore_backup.ps1 -BackupFile "backup\zone_monitoring_backup_2024-01-15_12-30-45.zip"
```

Скрипт автоматически:
1. Распакует архив
2. Создаст базу данных (если не существует)
3. Восстановит дамп БД

## Требования

- PostgreSQL должен быть установлен и доступен
- Утилиты `pg_dump` и `psql` должны быть в PATH или установлены в стандартных местах
- PowerShell 5.0 или выше

## Что включается в резервную копию

- Все исходные файлы проекта (Python, TypeScript, конфигурационные файлы)
- Дамп базы данных PostgreSQL
- Файлы миграций
- GeoJSON файлы карт
- Конфигурационные файлы

## Что исключается

- `node_modules/` - зависимости Node.js (можно восстановить через `npm install`)
- `__pycache__/` - кэш Python
- `.git/` - история Git
- `.venv/`, `venv/`, `env/` - виртуальные окружения Python
- `.env` - файлы с секретами (не копируются для безопасности)
- `dist/`, `build/` - скомпилированные файлы
- Логи и временные файлы

## Ручное восстановление БД

Если автоматическое восстановление не работает, можно восстановить БД вручную:

1. Распакуйте архив
2. Найдите файл `database_dump.sql`
3. Выполните команды:

```bash
# Создание БД
psql -h localhost -p 5432 -U zone_user -d postgres -c "CREATE DATABASE zone_monitoring;"

# Восстановление дампа
psql -h localhost -p 5432 -U zone_user -d zone_monitoring -f database_dump.sql
```

Или для custom формата:

```bash
pg_restore -h localhost -p 5432 -U zone_user -d zone_monitoring --no-owner --no-acl database_dump.sql
```

## Восстановление зависимостей

После восстановления файлов проекта:

### Backend:
```bash
cd backend
pip install -r requirements.txt
```

### Frontend:
```bash
cd frontend
npm install
```

## Примечания

- Файл `.env` не включается в резервную копию для безопасности. После восстановления создайте его вручную на основе примера.
- Убедитесь, что пароль БД в скрипте совпадает с вашим текущим паролем.
- Для больших проектов создание архива может занять некоторое время.
